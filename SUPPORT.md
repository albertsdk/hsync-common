# Support

hsync-common is a shared library, not a standalone application. For support with
the applications that use it, please refer to their documentation:

- **[HSYNC Server](https://github.com/albertobasso/hsync-server)** — central synchronization server
- **[HSYNC Client](https://github.com/albertobasso/hsync-client)** — command-line sync client
- **[HSYNC Desktop](https://github.com/albertobasso/hsync-desktop)** — desktop GUI
- **[HSYNC Android](https://github.com/albertobasso/hsync-android)** — Android app

For issues specific to the shared library itself:

- **[GitHub Issues](https://github.com/albertobasso/hsync-common/issues)** — bug reports and feature requests.
- **[Architecture Decision Records](docs/adr/README.md)** — the *why* behind the ecosystem's design decisions.
- **[Security Policy](SECURITY.md)** — how to report security vulnerabilities privately.

## 💚 Solo project

HSYNC is developed entirely by a single person in their spare time. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. The developer does their best to maintain and improve the project — thank you for your patience and support!
