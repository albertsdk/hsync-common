# Support

hsync-common is a shared library, not a standalone application. For support with
the applications that use it, please refer to their documentation:

- **[HSYNC Server](https://github.com/albertsdk/hsync-server)** — central synchronization server
- **[HSYNC Client](https://github.com/albertsdk/hsync-client)** — command-line sync client
- **[HSYNC Desktop](https://github.com/albertsdk/hsync-desktop)** — desktop GUI
- **[HSYNC Android](https://github.com/albertsdk/hsync-android)** — Android app

For issues specific to the shared library itself:

- **[GitHub Issues](https://github.com/albertsdk/hsync-common/issues)** — bug reports and feature requests.
- **[Architecture Decision Records](docs/internal/adr/README.md)** — the *why* behind the ecosystem's design decisions.
- **[Security Policy](SECURITY.md)** — how to report security vulnerabilities privately.

## 💚 Solo project

HSYNC is a passion project maintained in spare time by volunteers. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. Thank you for your patience and support!
